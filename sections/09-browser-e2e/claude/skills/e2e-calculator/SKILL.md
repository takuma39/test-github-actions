# 電卓の打鍵確認

最初に「[e2e-calculator 起動]」と1行だけ出力する。

## 前提

- 開発サーバーが `http://localhost:5173` で動いていること。つながらなければ、`pnpm dev` を別のターミナルで起動するよう利用者に頼んで止まる（自分で起動しない）
- ブラウザ操作は Playwright MCP のツールだけを使う。ファイルは編集しない

## 手順

1. `http://localhost:5173` を開き、ページのスナップショットを取る
2. フォームの要素は、スナップショット上のラベル（左辺・演算子・右辺）で特定する
3. 利用者に指定された計算を入力し、「計算する」を押して、結果の表示を読み取る
4. 指定がなければ `10 ÷ 2`、`10 ÷ 0` の2つを試す
5. 最後にスクリーンショットを1枚撮る

## 報告

入力・期待値・実際の表示・判定（OK / NG）を表にする。NG があれば、見えた事実だけを書き、原因の推測は書かない。
