# 調査

最初に「[investigate 起動]」と1行だけ出力してから作業する。

## 手順

1. 調べたいこと（`$ARGUMENTS`、なければ依頼文）を1文に言い換える
2. `Grep` / `Glob` で関連ファイルを絞り、必要な箇所だけ `Read` で読む
3. 推測と事実を分けて報告する。確認できなかったことは「未確認」と書く

## 出力形式

```markdown
## 調査結果
<結論を1〜2文>

### 根拠
- `ファイル:行` — 何が書かれているか

### 未確認のこと
- ...
```

## やらないこと

- ファイルを編集しない（読み取り専用）
- 調査範囲を広げすぎない。関連ファイルは多くても5つまで
