# 正解例（読み込まれない場所に置いている）

`.claude/skills/investigate/SKILL.md` の frontmatter を、次のように書き換えると起動しやすくなる。

```yaml
---
name: investigate
description: コードの挙動・処理の所在・不具合の原因を読み取り専用で調べ、根拠のファイルと行番号つきで報告する。「調査して」「どこで処理している？」「なぜ〜になる？」と言われたときに使う。コードの修正・実装、レビューには使わない。
---
```

直すポイント

- **何をするか**（挙動・所在・原因を調べて報告する）
- **いつ使うか**（利用者が実際に打つ言葉＝トリガー語を入れる）
- **使わない場面**（修正・レビュー。似た Skill との競合を防ぐ）
