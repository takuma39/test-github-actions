# 正解例（読み込まれない場所に置いている）

`local-review` の description に足すもの。ルートの `pr-review`（PR 担当）との競合を避けるために、対象を分ける。

```yaml
description: ローカルのファイル・未コミットの差分・ブランチの差分をレビューし、問題点を重要度付きで報告する。「レビューして」「コードを見て」「問題がないか確認して」と言われたときに使う。PR（プルリクエスト）のレビュー、コードの新規実装・修正には使わない。
```

ポイントは最後の一文。「PR のレビューには使わない」と書くと、PR 担当の `pr-review` と役割が分かれる。
