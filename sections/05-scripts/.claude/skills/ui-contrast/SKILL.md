# UI 配色の検査

最初に「[ui-contrast 起動]」と1行だけ出力する。

## 手順

1. 対象の CSS（`$ARGUMENTS`、なければ依頼で指定されたファイル）から、文字色と背景色の組み合わせを洗い出す
2. 組み合わせごとに、次の検証を**実行する**（読むのではなく実行）

   ```bash
   python3 "${CLAUDE_SKILL_DIR}/scripts/validate_colors.py" "<文字色HEX>" "<背景色HEX>"
   ```

   - HEX は必ず引用符で囲む（`#` 以降がシェルのコメントになり、引数が消えるため）
   - 大きい文字（24px 以上、または太字 18.66px 以上）は `--large` を付ける
   - 終了コード 0 = AA 合格 / 1 = 不合格 / 2 = 入力エラー
3. FAIL の組み合わせは、スクリプトの「次の行動」に従って色を直し、**再検証して PASS を確認する**
4. FAIL のまま完了しない

## 報告

組み合わせ・コントラスト比・結果を表にして報告する。直した箇所は「元の色 → 修正後の色」で書く。
